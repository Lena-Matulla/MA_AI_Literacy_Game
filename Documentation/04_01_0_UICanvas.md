# UI Canvas

## Purpose
Overlay which contains the "all the time" overlay which contains the TrustValue points and the Level, as well as the Tutorial and quit button. But also contains other parts like the tutorial, which is only active when needed

## Components
- SliderBox
- Level
- QuitButton
- TutorialButton
- Tutorial
- 5MinLeftNotification
- TimeUpPopUp
- TeminderToCloseImgGame

## Responsibilities
- display current points and how much more is needed for the next level
- Update and display Level
- Display Tutorial and Quit Buttons
- Hold the Tutorial, and the notifications
