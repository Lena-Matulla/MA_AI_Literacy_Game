# System

The Game is divided in different Groups through empty parents and blocks in the Hierarchy.

- UI Canvas, which includes the Canvas which spans over the whole screen all the time, which is the Level and Trustvalue Bar.
- The Office block containing the Camera, the OfficeRoot and the A* (which is a plugin for the npcs to be able to walk around through path finding algorithm)
- The Desk block containing the Camrea as well as the Desk with the clickable items
- The ImageGame, which contains all features needed for the Image decision part of the Game
- Two more Managers, the ProgressManager and the Save Manager

All of them will be explained further in the next files.
