# Structure

## Assets
Contains the Game folder game and its regarding files.
Also contains the Tileset folder, in which the used Tileset lies which was paid for.
As well as the Resources Folder where the Images are in.
It also contains the Scenes Folder with the Scene Game, which is the Game itself.

## Assets/Game
Contains Images, Prefabs and Scripts.

## Assets/Game/Images
Contains old unused folders.
But also contains for example the texture of the desk and computer background as well as the props.

## Assets/Game/Prefabs
Contains the ImageGame prefab which refers to the image decider as its own. (was done before making the rest of the game)

## Assets/Game/Scripts
Contains two folders:
- Desk
- OfficeUpdateSystem
  
and many unsorted Scripts which contain the game logic

The scripts are explained in seperate files.
